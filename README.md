RIPTIDE NETWORK
================

An ever-growing collection of assets, visual resources, and
customization options for Riptide.

Repository:    https://github.com/securly-is-trash/riptide
Browse Assets: https://github.com/securly-is-trash/riptide/tree/main
Report Issue:  https://github.com/securly-is-trash/riptide/issues


--------------------------------------------------------------------
ABOUT
--------------------------------------------------------------------

Riptide Network is a centralized, community-driven library of
resources built to support and expand the Riptide ecosystem.

The repository brings together reusable assets for visual
customization, interface design, and audio. Whether you're looking
for backgrounds, custom cursors, fonts, effects, or other creative
resources, Riptide Network makes them easier to discover and
integrate.

The collection is designed to grow over time, with contributions that
add new assets, improve organization, and expand the ways Riptide can
be customized.

CONTRIBUTING
--------------------------------------------------------------------

Riptide Network is intended to grow with its community. Contributions
are welcome, whether you're adding new resources, improving existing
collections, or helping keep the repository organized.

How to Contribute

  1. Fork the repository.
  2. Create a branch for your contribution.
  3. Add your assets to the most appropriate directory.
  4. Use clear, descriptive filenames and keep files organized.
  5. Submit a pull request with a brief description of your changes.

Before submitting, make sure you have the rights to share the assets
and that they are suitable for redistribution. Include attribution or
licensing information when required.


--------------------------------------------------------------------
LICENSE & ATTRIBUTION
--------------------------------------------------------------------

Assets in this repository may come from different creators and
sources, and their usage terms may vary. Check the license and
attribution requirements for each asset before reusing, modifying, or
redistributing it.

If you contribute an asset, make sure its source and licensing
information are clear.
