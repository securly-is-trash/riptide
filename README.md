## About

Riptide Network is a centralized collection of resources designed to support and expand the Riptide ecosystem.

From visual customization to audio resources, the repository serves as a growing library of assets that can be reused, integrated, and contributed to by the community.

Whether you're looking for backgrounds, custom cursors, visual effects, or additional interface resources, Riptide Network provides an organized place to find them.

## Contributing

Riptide Network is intended to grow alongside its community.

Contributions that expand the asset library, improve organization, or introduce new resources are welcome.

### How to Contribute

1. Fork this repository.
2. Create a branch for your contribution.
3. Add your assets to the appropriate directory.
4. Keep filenames descriptive and organized.
5. Submit a pull request for review.

Please ensure that submitted assets are appropriate for redistribution and that you have permission to share them.
